# Exercises — Practice with Solutions

> **Level:** L1–L3 · **Area:** Exercises

Practice problems that mirror what you'll be asked to do on a real Anaplan build. Each file has a
matching **worked solution** in [`solutions/`](solutions/) — try the exercise first, then check.

Everything here uses the same canonical **FP&A revenue → P&L** model as the
[tutorials](../tutorials/) and [blueprints](../blueprints/fpa-pl-planning/), so the lists
(`Region`/`Entity`, `Product`), modules (`SYS/INP/CAL/OUT`) and conventions will already be familiar.

---

## How to use

1. Read the exercise. Attempt it **on paper** as a blueprint table / Anaplan formula — you don't
   need a tenant (Anaplan doesn't run outside a browser; see the [repo README](../README.md)).
2. Write your answer using the [blueprint template](../templates/blueprint-template.md) and
   [naming conventions](../templates/naming-conventions.md).
3. Open the matching solution and compare — the **explanation** matters more than the exact formula.
